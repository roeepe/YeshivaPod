# YouTube Playlist to Podcast Automator

פרויקט זה ממיר באופן אוטומטי פלייליסט מיוטיוב לפודקאסט (RSS Feed) שניתן להעלות לספוטיפיי ולכל פלטפורמה אחרת. המערכת מבוססת על GitHub Actions ו-GitHub Releases, כך שהיא **חינמית לחלוטין ופועלת אוטומטית ללא מגע אנושי**.

## איך זה עובד?
1. ה-GitHub Action מוגדר לרוץ פעמיים בשבוע (ראשון ושני ב-02:00 בלילה), או בלחיצת כפתור באופן ידני.
2. הסקריפט יוריד מידע על הפלייליסט שהגדרת.
3. לכל סרטון חדש שטרם עובד, הוא יוריד את קובץ השמע שלו כ-MP3 באמצעות `yt-dlp`.
4. הוא יעלה את ה-MP3 בתור 'Release Asset' ב-GitHub כדי לקבל קישור ישיר לקובץ.
5. לבסוף, הוא יעדכן את קובץ ה-`rss.xml` וישמור אותו במאגר.
6. GitHub Pages יחשוף את ה-`rss.xml` לעולם, כך שספוטיפיי יוכלו לקרוא אותו!

## הוראות התקנה (חד פעמי!)

### שלב 1: פתיחת פרויקט ב-GitHub
1. פתח חשבון ב-[GitHub](https://github.com) (אם אין לך עדיין).
2. צור מאגר (Repository) חדש ו**ציבורי** (Public).
3. העלה את כל הקבצים שבתיקייה זו אל המאגר החדש שיצרת (אפשר פשוט לגרור את הקבצים לממשק האתר).

### שלב 2: הגדרת הרשאות ל-GitHub Action
כדי שהסקריפט יוכל לעדכן את קבצי ה-RSS ולהעלות את פרקי השמע, עליך לאשר לו כתיבה למאגר:
1. כנס ל-**Settings** במאגר שלך ב-GitHub.
2. בתפריט הצדדי בחר **Actions** ואז **General**.
3. גלול למטה עד ל-**Workflow permissions**.
4. בחר ב-**Read and write permissions** ולחץ על **Save**.

### שלב 3: הפעלת GitHub Pages
כדי שה-RSS Feed שלך יהיה זמין לספוטיפיי:
1. כנס שוב ל-**Settings** של המאגר.
2. בתפריט הצדדי בחר ב-**Pages**.
3. תחת **Source**, בחר ב-`Deploy from a branch`.
4. תחת **Branch**, בחר ב-`main` (או `master`) ולחץ **Save**.
5. המתן כמה דקות. יופיע לך לינק בחלק העליון של הדף בסגנון: `https://yourusername.github.io/your-repo-name/`. ה-RSS שלך יהיה בכתובת `https://yourusername.github.io/your-repo-name/rss.xml`.

### שלב 4: הרצה ראשונית
1. כנס ללשונית **Actions** בחלק העליון של עמוד המאגר ב-GitHub.
2. מצד שמאל תראה `Update Podcast RSS Feed`. לחץ על זה.
3. לחץ על הכפתור האפור **Run workflow** והרץ את הסקריפט.
4. בהרצה הראשונה הוא יוריד את כל הסרטונים הקיימים (זה עשוי לקחת קצת זמן).

### שלב 5: חיבור לספוטיפיי
1. כנס ל-[Spotify for Podcasters](https://podcasters.spotify.com/).
2. בחר באפשרות להוסיף פודקאסט קיים באמצעות RSS Feed.
3. הדבק את הכתובת של ה-RSS שלך (משלב 3: `https://yourusername.github.io/your-repo-name/rss.xml`).
4. זהו! ספוטיפיי ישאבו את הפרקים, ומעתה הכל יקרה אוטומטית בכל שבוע.

## עריכת פרטי הפודקאסט
אם תרצה לשנות את השם, התיאור, התמונה או פלייליסט היוטיוב, פשוט ערוך את הקובץ `podcast_info.json` ודחוף את השינויים ל-GitHub. בהרצה הבאה, הפודקאסט יתעדכן.
